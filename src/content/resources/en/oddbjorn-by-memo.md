In this episode the host, Jan Sindre, recommends the books of **Oddbjørn By**. By is a
Norwegian memory expert who has worked full time on memory technique since 2005, and
set a world memory record in 2006.

The Memo books are first and foremost about **memory technique**: concrete methods for
fixing information in memory, not least by tying it to images, places and associations
– as in a memory palace.

## The books

- **Memo – husketeknikker for elever, studenter og alle som skal lære seg noe.**
  The foundation of the series: a practical introduction to memory technique.
- **Bedre hukommelse – best of memo.** A collection of the best techniques from the
  Memo books.
- **Memo: Lær tysk / spansk / italiensk.** Memory technique applied to language
  learning.
- **Memo medisin** (written with Sebastian S. S. Schmidt). Memory technique aimed at
  medical students.

## Why it is worth a look

Memory technique is not only for exam revision. The methods are useful for anyone who
wants to remember more day to day – names, numbers, lists, languages or course
material. A good starting point is to try things out and find the method that suits
the way you learn.

> If you want to learn more about the learning process itself – reading, note-taking
> and revision – Olav Schewe's books are a natural next step.
