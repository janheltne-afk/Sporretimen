How is it possible to remember 52 cards in the right order? The answer is neither
talent nor a photographic memory – it is a **system**, and it can be learned.

In this Learn something new episode Jan Sindre goes through the memory techniques
behind it: how you build a **memory palace**, how each card is turned into a distinct
image, and how those images are placed along a route you already know. We also look
at the **PAO system**, where every card gets a person, an action and an object – so
that several cards can be packed into a single memory.

The point is not the deck of cards in itself. It is understanding why the brain
remembers images and places so much better than numbers and symbols – and how you can
use the same trick on names, course material, shopping lists and presentations.

*The content is practical knowledge you can practise yourself. Sources and further
reading are given in the episode.*
